# Power BI Customer Churn Analysis

## 📌 Overview
This project uses Power BI to analyse customer churn within a telecommunications dataset. The goal was to identify churn patterns, key drivers, and customer segments at higher risk of leaving.

## 🛠 Tools Used
- **Power BI**
- DAX
- Power Query

## 📊 Dataset
- ~7,000 customer records  
- Includes contract type, tenure, payment method, and monthly charges  

## 📊 Dashboard Features
- Overall churn rate  
- Average customer tenure  
- Average monthly charges  
- Churn breakdown by contract type  
- Churn analysis by payment method  

## 🔍 Key Insights
- Higher churn among **month-to-month contracts**
- Customers paying via **electronic cheque** showed increased churn risk
- Churn decreases as customer **tenure increases**

## 🧮 DAX Measures Used
- Churn Rate  
- Average Tenure  
- Average Monthly Charges  
- Customer Counts and Segmentation  

## ✅ Skills Demonstrated
- Building interactive Power BI dashboards  
- Writing DAX measures  
- Insight generation and data storytelling
